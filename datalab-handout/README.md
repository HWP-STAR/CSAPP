# 对于 n 位补码（1 <= n <= 32）：

最小值：-2^(n-1)
0是分界线，也是正的一边
最大值：2^(n-1) - 1

对于二进制补码，判断一个数能否用 n 位表示，等价于：将 x 右移 n-1 位后，结果要么全是 0，要么全是 1。（n-1是有用的，一位来表示符号）

如果 x 能表示，则高出的位（从第 n 位到第 31 位）必须全部相同（全 0 或全 1）

因为高出的位只是符号位的扩展

# 核心思想：检查符号扩展是否正确
右移 n-1 位：x >> (n-1)

如果 x 能表示，结果应为 0（正数）或 -1（负数,对于补码全是1）

如果 x 不能表示，结果会是其他值

 检查结果是否为 0 或 -1

转化为位运算：检查结果加 1 后是否为 0 或 1

对于结果 y：

如果 y == 0，y + 1 == 1

如果 y == -1，y + 1 == 0

如果 y == 0 或 y == -1，(y + 1) >> 31 的结果是 0（因为 0 或 1 右移 31 位为 0）

如果 y 是其他值，(y + 1) 会是一个范围外的值，其符号位可能为 1

# 对2的整除,C 语言的除法 / 是向零舍入。
正数：直接>>
对于负数：需要加偏置
对于负数，简单的右移是向下舍入（向 -∞），而不是向零舍入。

以 -33 / 16 为例：

算术右移 4 位：-33 >> 4 = -3（因为 -33 的二进制是 111...1101111，右移后得到 -3）

期望结果：-2（向零舍入）

差异：需要加一个偏置 (1 << n) - 1，即 (1 << 4) - 1 = 15

偏置值 = (1 << n) - 1 = 2ⁿ - 1

# 将整数 x 转换为单精度浮点数，返回其位级表示（unsigned int）

解题思路
步骤分解
处理特殊情况：

如果 x == 0，返回 0

处理符号：

如果 x < 0，符号位为 1，并将 x 转为正数

找到最高位 1 的位置：

从最高位开始找，找到第一个 1 的位置

这就是指数 exp

提取尾数：

最高位 1 之后的 23 位就是尾数

如果不足 23 位，后面补 0

舍入处理：

如果截断的部分大于 0.5，进位

如果等于 0.5，看尾数最低位（银行家舍入）

如果小于 0.5，舍去

组装结果：

符号位 << 31 | (指数 + 127) << 23 | 尾数
